# 📈 Stock Portfolio Tracker

A beginner-friendly Python project that helps users calculate and track the value of their stock investments.

## 📌 About the Project

The Stock Portfolio Tracker is a simple Python application that allows users to select stocks, enter the number of shares they own, and calculate the total value of their investments.

The project uses a predefined dictionary of stock names and prices to calculate individual investment values and the total portfolio value. It also provides an option to save portfolio details to a CSV file.

This project was developed to practice Python programming fundamentals and understand how to build a practical, real-world application.

## ✨ Features

* 📊 Displays a list of available stocks.
* 💰 Calculates the investment value of individual stocks.
* 🧮 Calculates the total portfolio investment.
* 🔢 Accepts stock quantities from the user.
* ✅ Validates stock names and share quantities.
* 💾 Saves portfolio details to a CSV file.
* 📋 Displays a summary of the user's stock portfolio.

## 🛠️ Technologies Used

* **Python** — Core programming language.
* **CSV Module** — Stores portfolio information in a CSV file.
* **Dictionary and Loops** — Manage stock prices and process user input.
* **Conditional Statements** — Validate user input.

## 🚀 Getting Started

### Prerequisites

* Python 3 installed on your computer.
* A code editor such as Visual Studio Code.

### Installation

**1. Clone this repository:**

```bash
git clone https://github.com/marooff18/stock-portfolio-tracker.git
```

Replace `marooff18` with your GitHub username.

**2. Open the project folder:**

```bash
cd stock-portfolio-tracker
```

**3. Run the Python program:**

```bash
python stock_tracker.py
```

## 💻 How to Use

1. Run the program.
2. View the list of available stocks.
3. Enter the number of different stocks you want to track.
4. Enter a stock name.
5. Enter the quantity of shares you own.
6. View the investment value of each stock.
7. View your total portfolio investment.
8. Choose whether to save your portfolio details to a CSV file.
